<h1 align="center">VOZEB PRO</h1>

<p align="center">面向多模态内容创作、可视化编排与短剧生产的一体化 AI 创作系统</p>

## 系统概述

VOZEB PRO 将 AI 对话、图片、视频、音频、Canvas、短剧生产、素材管理和平台运营整合在同一套系统中。用户可以在统一工作流中完成内容规划、模型调用、结果管理和作品发布，管理员可以集中配置模型渠道、商品计费、内容运营、存储和系统安全。

## 统一创作 Agent

- 支持普通对话、图片、视频和音频四类创作任务。
- 支持上传参考图片和视频，并可为视频指定首帧或首尾帧素材。
- 根据用户需求规划创作类型、模型和生成参数，也可由用户手动选择。
- 支持比例、画质、清晰度、时长、音色、格式、数量和自定义尺寸等参数。
- 以对话形式保存创作过程，支持历史恢复、任务续接、失败重试和结果下载。
- 支持引用当前会话素材、个人素材和提示词继续创作。

## 图片、视频与音频工作台

- 提供面向单一媒体类型的独立创作界面和参数配置。
- 支持多结果生成、预览、切换、下载、删除和再次引用。
- 图片支持精确尺寸、参考图比例继承和生成结果规范化。
- 视频支持普通参考、首帧和首尾帧生成方式。
- 音频支持音色、格式等生成偏好。
- 同一对话中的多轮生成结果可持续聚合展示并恢复。

## Canvas 可视化创作

- 支持文本、图片、视频、音频和生成任务节点。
- 支持节点拖拽、连线、缩放、撤销、重做、导入和导出。
- 可通过节点关系组织素材、提示词和生成任务，形成可复用工作流。
- 支持图片元素识别、独立分层、背景补全和节点化结果管理。
- Canvas Agent 可基于当前画布内容规划并执行创作任务。

## 短剧生产

- 以项目和剧集为单位管理完整生产流程。
- 支持剧本编辑、内容审核、分镜设计和镜头生成。
- 集中管理角色、场景、道具、线索和来源素材。
- 支持资产基准图、候选图、镜头引用和项目级复用。
- 支持视频、配音、字幕、版本记录和成片合成。
- 展示各生产阶段的真实状态、阻塞原因和失败项，并支持精确重试。

## 素材与提示词

- 统一管理本地上传和系统生成的图片、视频与音频素材。
- 支持素材检索、预览、引用、下载、删除和存储迁移。
- 支持个人提示词、平台提示词库、分类筛选和快速插入。
- 支持由管理员维护 Agent Skills，并在用户明确选择后参与任务执行。

## 作品与内容发布

- 支持作品草稿、版本管理、审核、发布、下架和重新发布。
- 提供作品广场、作品详情和创作者主页。
- 支持检索、点赞、关注、分享和举报。
- 管理端可处理内容审核、违规治理和平台公告。

## 账号与商业运营

- 支持用户注册、登录、找回密码、个人资料和账号安全管理。
- 支持套餐、商品、促销、优惠券、邀请奖励、积分和 CDK。
- 支持充值、支付订单、退款、对账和财务流水。
- 支持余额与用量管理，并记录业务操作和资金变化。
- 管理端可统一管理用户、商品、订单、支付渠道和经营数据。

## 模型与渠道管理

- 集中配置模型供应商、接口协议、渠道密钥和请求参数。
- 支持文本、图片、视频和音频模型及其能力配置。
- 支持逻辑模型、真实模型、优先级、默认值和可用范围管理。
- 支持系统渠道代理和声明式自定义协议适配。
- 密钥和渠道配置仅在服务端使用，避免暴露到浏览器。

## 任务与运行管理

- 独立 Worker 持续处理图片、视频、音频和 Agent 任务。
- 页面刷新、关闭或服务实例切换后，可恢复进行中的任务。
- 保存上游任务身份和查询状态，避免重复提交与重复计费。
- 管理端提供生成任务查询、异常处理和运行状态检查能力。

## 存储、数据与安全

- 业务数据使用 PostgreSQL 持久化。
- 媒体支持服务器本地存储和 S3 兼容对象存储。
- 支持对象迁移、引用保护、业务数据备份和恢复。
- 管理端操作使用会话鉴权、职责权限和脱敏审计。
- 支持管理员登录挑战、可选多因素认证和敏感配置保护。
